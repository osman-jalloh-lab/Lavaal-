# Independent audit checklist

- [ ] Build runs locally using documented commands
- [ ] No real API/network/secret access from the demo
- [ ] No production writes or deployments
- [ ] Both character variants work and share the same animation engine
- [ ] All chat events are mocked and easy to integrate later
- [ ] Brand sources documented; no guessed colors presented as official
- [ ] Reduced motion, keyboard use, pause/hide controls work
- [ ] Mobile viewport and overlay collision tests pass
- [ ] Tests pass with actual logs supplied
- [ ] Asset rights and dependencies reviewed
- [ ] Bundle size, CPU/battery impact, and idle behavior measured or documented
- [ ] No fake consent, webhook submission or spend-control claims
- [ ] Safe branch/PR plan prepared for a future approved integration
