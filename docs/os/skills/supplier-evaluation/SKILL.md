# Supplier Evaluation

Score suppliers with evidence before outreach volume. Research/scoring = L1; outbound contact = L3 via supplier-outreach + founder.

## Score dimensions (0–5 each, with notes)
1. **MOQ / deal fit** — can serve quote-first small-to-mid deals
2. **Shipping to West Africa** — SL first; GN, GW, LR relevance
3. **Payment terms** — clarity; methods discussed after quote (not a score for “supports Orange Money” unless evidenced)
4. **Territory / authorization** — written or primary-source confirmation for brands/countries
5. **References / reputation** — citable
6. **Responsiveness path** — clear contact channel

## Steps
1. Name the supplier and what product lane is under review.
2. Gather **primary sources** only (official partner pages, distributor lists, written confirmations). Cite URL or doc for each claim.
3. Mark UNKNOWN rather than guessing (especially brand territory for SL).
4. Fill scorecard; compute simple average; list blockers (e.g. missing legal entity docs, unverified authorization).
5. Recommend: pursue / hold / drop — and whether supplier-outreach draft is warranted.
6. Do not contact the supplier inside this skill.

## Completion criteria
- [ ] Scorecard complete with citations or UNKNOWN
- [ ] Blockers listed
- [ ] Clear pursue/hold/drop recommendation
- [ ] No outbound send
