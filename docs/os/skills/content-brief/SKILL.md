# Content brief
1. Confirm the topic row on the ideas board.
2. Read the current top results and AI answers for the main query. Note what they cover and what they miss.
3. Write the brief:
   - target query and its variants;
   - search intent and audience;
   - suggested title and H1;
   - outline in H2s and H3s;
   - the questions it must answer (pulled from the question map);
   - points that set it apart;
   - internal links;
   - sources to cite;
   - call to action.
4. Every number or claim in the brief needs a source. Never write the finished article.
5. Save it as briefs/YYYY-MM-DD-<slug>.md, or deliver it where the user's brief destination says. Set the board row to briefed.
6. It's a draft by default, and nothing gets published or sent without the user's yes.
