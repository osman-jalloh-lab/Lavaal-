# Question map
1. Collect real questions from People Also Ask, forums, reviews, support inbox themes and AI-assistant answers to the seed topics.
2. Group them by theme and intent. For each, note who the AI answers and top results currently cite. Only record citations you actually saw.
3. Mark which questions the site already answers, answers weakly, or doesn't answer.
4. Update question-map.md, and add any gaps worth a page to the ideas board.
5. Reply with the top gaps and one recommendation.
