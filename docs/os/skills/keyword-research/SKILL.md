# Keyword research
1. Expand the seeds from the agreed keyword source (a connected tool, Search Console, autocomplete, People Also Ask, forums or competitor pages).
2. Group the results by search intent into page ideas, one page per intent.
3. Rank by fit with what they sell, intent and the gap against competitors. Show volume or difficulty only when a real tool gave it, and name the source.
4. Never invent a volume, difficulty, position or click. If data is partial, say so.
5. Add or update rows on the ideas board (status: idea). Check the board for duplicates first.
6. Reply with the top ideas: one line each saying why it's worth doing, plus one recommendation.
