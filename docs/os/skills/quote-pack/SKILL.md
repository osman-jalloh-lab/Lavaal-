# Quote Pack

Core commercial motion for quote-first sourcing (not checkout). Never invent prices, stock, lead times, or authorizations.

## Steps
1. **Intake** — summarize customer ask, market (SL/GN/GW/LR), channel, constraints from Sheet/inbound.
2. **Clarifiers** — list only missing facts that block a real quote (model/spec, qty, delivery city, timeline, budget band if offered).
3. **Sourcing path** — which suppliers/lanes might cover this (pointer to supplier-evaluation); note UNKNOWNs.
4. **Quote outline** — line items as specs/qty/TBD price; shipping and tax as TBD unless evidenced; payment methods listed as **options to agree after quote** (bank transfer, Orange Money, AfriMoney, MoneyGram) — not as confirmed terms.
5. **Customer reply draft** (optional, L1) — short, plain; ask clarifiers or present outline with TBD prices. **Send = L3 stop.**
6. permission-gate before any external message.

## Completion criteria
- [ ] Clarifiers listed or marked none
- [ ] Outline has no fabricated prices
- [ ] Payment framed as post-quote agreement
- [ ] Send not performed unless separately founder-approved
