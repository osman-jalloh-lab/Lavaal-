# Page audit
1. Pull the page's real numbers (clicks, impressions, position) from Search Console or another connected tool, and compare them with the last saved report. Never estimate them.
2. Check the page against the query and intent, against current competitors, and for freshness, technical problems (indexing, speed, schema) and internal links.
3. Check whether AI answers cite the page or a competitor for its main questions.
4. List fixes in priority order, with the evidence for each.
5. Save it as audits/YYYY-MM-DD-<slug>.md. Make no changes to the live page without the user's yes.
