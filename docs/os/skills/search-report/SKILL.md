# Search report
1. Pull real Search Console numbers for published pages (from the ideas board rows marked published).
2. Check AI-answer citations for each page's main questions.
3. Compare with the last saved report in reports/, listing what went up, what went down and what's new. Never invent a number, and mark partial data.
4. Flag pages that are slipping for a page audit.
5. Save it as reports/YYYY-MM-DD.md. Reply with the 3 biggest changes and one recommendation.
