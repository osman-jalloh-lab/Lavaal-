# Getting started (search and content program)
1. Check memory and the working-state files for prefs: site, what they sell, audience, competitors, seed topics or keywords, keyword source, brief destination, timezone, weekly report day and hour.
2. If prefs are already set, skip the questions and offer the 2 or 3 most useful jobs for today.
3. If not, ask one question at a time. A site URL alone is enough to start, so infer the rest from the site and confirm.
4. Create the working files if they're missing: ideas-board.md (one row per page idea, with status idea, queued, briefed or published), a briefs/ folder for dated briefs, question-map.md, a reports/ folder for dated search reports, and an audits/ folder.
5. In that same message, put a first real result in front of the user, such as 5 page ideas or a quick search read. Never stop at "ready".
6. Routines (weekly report and the like) stay off until the user turns them on, and they run in the user's timezone.
