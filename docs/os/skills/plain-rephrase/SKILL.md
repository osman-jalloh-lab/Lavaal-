# Plain Rephrase

Rewrite confusing or dense text into plain, short language. Founder preference: extremely simple, organized, one short page — not multi-doc packs. Supplier tone is casual and phone-first, not formal RFQ.

**Inspiration:** Simplified Technical English / wait-what pattern (Matt Pocock skills, MIT) — adapted for LAVAALL glossary (sourcing not marketplace; quote-first).

## Steps
1. Identify the audience (founder, supplier, customer, internal bot).
2. Extract the must-keep facts; drop filler and duplicate restatements.
3. Rewrite: short sentences, concrete words, active voice; keep EN plain (FR/Krio only if source requires).
4. Preserve meaning: no new claims (“200+ clients”, authorized reseller, prices) unless in source.
5. Return the rewrite plus optional one-line “what changed.”

## Completion criteria
- [ ] Shorter and clearer than input
- [ ] No invented facts, prices, or authorizations
- [ ] Tone matches audience (casual for supplier outreach drafts; plain for founder docs)
