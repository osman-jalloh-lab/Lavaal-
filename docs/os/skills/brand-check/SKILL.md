# Brand Check (LAVAALL)

Review customer-facing material against LAVAALL voice and confirmed claims. Draft and flag only unless founder approved publish (L3).

## Authority sources (read these; do not invent brand rules)
- OS: `brand/voice-and-tone.md`, `context/company.md`, `context/GLOSSARY.md`
- Public site: https://www.lavaall.com
- Catalog / visuals detail: MAGNUM.md in GitHub `Lavaal-` (treat fonts/colors as LIKELY until founder reconfirms)

## Check list
1. **Tone** — clear, professional, friendly; supplier drafts may be casual/phone-first
2. **Model language** — quote-first **supplier/sourcing**; do not say marketplace checkout
3. **Claims** — only founder-verified claims (e.g. 200+ clients, 500+ projects, Since 2018); no new unverified boasts
4. **Markets** — Sierra Leone and Liberia; Guinea (Conakry) is blocked (since Oct 6); Guinea-Bissau: not decided, ask Osman; do not invent markets
5. **Payments** — bank / Orange Money / AfriMoney / MoneyGram are **after quote**, not checkout promises
6. **Starlink** — progress OK as priority; never claim authorized reseller unless founder says so
7. **Localization** — EN / FR / Krio consistency when the piece is multi-language; note gaps, do not invent translations casually
8. **Support** — prefer support@lavaall.com for public support contact
9. **Plain language** — prefer short plain wording over dense jargon
10. **AI people** — an AI-made person shown as a customer, reviewer or testimonial = **FAIL** (blocker)
11. **Third-party rights** — a third-party product, brand or logo used without rights = **FAIL** (blocker)
12. **AI asset approval** — any AI-generated image, video, voice or music without Osman's per-item OK on record = **FAIL** (blocker; FR-027 as amended 7 Oct 2026). A credit OK is not an asset OK.

## Output
- PASS / PASS WITH NOTES / FAIL
- Bullet list of issues with severity (blocker / polish)
- Suggested rewrite for blockers (keep short)
- APPROVAL: whether publish/send needs founder (usually yes for social/ads/email send)

## Permission
- L1 review and rewrite drafts
- L3 for publish or outbound send; L4 for paid ads — stop and ask founder

## Completion criteria
- [ ] PASS / PASS WITH NOTES / FAIL stated
- [ ] Each issue has severity
- [ ] Model language and unverified claims checked
- [ ] AI-person, third-party-rights and AI-asset-approval lines checked
- [ ] Publish/send gate called out if relevant
