# Research Primary (LAVAALL)

Investigate a question against **high-trust primary sources**, then save a short cited note. Do not invent prices, legal conclusions, or metrics.

**Inspiration:** Matt Pocock `research` (MIT) — adapted for LAVAALL OS notes and Level 0–4 gates.

## Source priority (highest first)
1. Official / regulatory authorities for the jurisdiction
2. Primary sources (manufacturer, distributor, first-party docs, source code, specs)
3. First-party company docs (lavaall.com, MAGNUM, founder-confirmed OS context)
4. Reputable secondary research **only** when primary evidence is unavailable — label clearly

## Claim record (every material claim)
- claim
- source
- source URL
- publication / effective date (if available)
- date checked
- confidence: CONFIRMED | LIKELY | UNKNOWN | CONFLICT
- business implication (one line)

Separate **confirmed facts** from **assumptions**.

## Steps
1. Restate the research question in one sentence.
2. Prefer primary sources; follow each claim back to the owner of the fact.
3. Write findings as Markdown under LAVAALL OS / discovery notes (match existing convention).
4. Include an executive summary (≤5 bullets) + claim table.
5. Save **durable** findings into OS context only when they are confirmed and useful company-wide — not every search hit.
6. Permission: **L0–L1** read/research. Do not send outreach, file regs, or change production. If the answer implies a consequential choice, hand off to [grill-founder](sand-workflow:grill-founder) or [decision-log](sand-workflow:decision-log).

## Completion criteria
- [ ] Question restated
- [ ] Material claims have claim/source/URL/date-checked/confidence/implication
- [ ] Confirmed vs assumptions separated
- [ ] Note path reported
- [ ] No secrets, fake prices, or unauthorized legal advice presented as authority
