# Grill Founder

Relentless but respectful interview to clear **founder decisions**. Facts are the agent’s job; decisions wait for the human.

**Inspiration:** Matt Pocock grilling / grill-me patterns (MIT) — adapted for LAVAALL OS, plain English, phone-first culture.

## Rules
- Prefer facts from memory, connected sources, MAGNUM/site, Sheet, discovery docs — **before** asking.
- Ask only **unresolved decisions** (trade-offs the founder must pick).
- One frontier question at a time when possible; offer a recommended answer with rationale.
- Keep language plain and short (founder preference). Light grill for casual supplier tasks; fuller rounds for OS/policy/money.
- Do not implement L3–L4 outcomes mid-grill without approval.

## Steps
1. State the decision tree in one short paragraph.
2. List known facts (bullets) vs open decisions (bullets).
3. For each open decision: ask, recommend a default, note risk if wrong.
4. Stop when the frontier is empty or founder pauses; summarize decisions taken.
5. Optional: point to decision-log / OS note update (L2) — do not invent approval for external actions.

## Completion criteria
- [ ] Facts gathered without unnecessary questions
- [ ] Only decision questions asked
- [ ] Each answered decision recorded in plain English
- [ ] Remaining open items listed or frontier empty
